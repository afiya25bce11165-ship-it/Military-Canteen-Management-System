# Military-Canteen-Management-System
The **Canteen Management System** is a software program that can perform canteen management activities such as managing customers, products, stock, and sales. It can be developed by utilizing **Python and MySQL**, which can efficiently handle data. The system can help minimize work, errors, and increase efficiency in canteen management.

## 🌟 Canteen Management System
### 📌 Project Overview
The Canteen Management System is a Python-based application developed as a Computer Science project to automate the management of canteen operations. The system integrates a Python interface for user interaction with a MySQL database for secure data storage and management.
It allows administrators to efficiently manage customers, products, inventory, and sales records, reducing manual work and improving the speed and accuracy of canteen transactions.

### 📂 Database Structure
The system uses four main MySQL tables to manage data.
Customer Table
Stores customer information such as:
Customer ID
Customer Name
Address
Phone Number
Product Table
Maintains product inventory details:
Product ID
Product Name
Company
Price
Quantity
Discount
Rate
Purchase Date
Purchase Table
Records product purchase transactions:
Customer ID
Product ID
Quantity
Amount
Sale Date
Product Report Table
Maintains product purchase reports:
Product ID
Purchase Date
Payment Status
Due Amount
